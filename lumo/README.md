# LUMO App
**Business management web application**

[Back to PROJECTS](../README.md)

## Overview

LUMO is an independent software project for small businesses and entrepreneurs to manage sales, payments, expenses, customers, and accounts receivable.

## My contribution

I develop the React interfaces, application logic, and integration with authentication and data services.

## Implemented scope

- Sales, payment, expense, and customer management
- Dashboards and data visualization
- Accounts receivable tracking, including pending and overdue payments
- CSV exports
- PDF billing document generation

## Technologies

React · JavaScript · HTML · CSS · Supabase · Chart.js · jsPDF

MVP in development. Features and implementation may change as the project evolves.
