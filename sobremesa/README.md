# Sobremesa
**3D café management game — Web and Android development**

[Back to PROJECTS](../README.md)

## Overview

Sobremesa is an independent café management and life simulation game set in a stylized interpretation of Manizales, Colombia.

## My contribution

I work on gameplay programming, interactive system design, and the browser-based 3D experience. The project is also being developed for Android using Android Studio, alongside performance testing in the Android ecosystem.

## Project scope

- Interactive 3D environments
- Player interactions and gameplay logic
- Production systems
- Resource management
- Ongoing Android development using Android Studio
- Performance testing for the Android ecosystem

## Technologies

JavaScript · Three.js · HTML · CSS · Git · Android Studio

## Status

In development since September 2026. Originally built for the browser; Android development and Android performance testing are now in progress. No Android release or benchmark results are claimed in this overview.
