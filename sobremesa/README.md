# Sobremesa
**Browser-based 3D café management game**

[Back to PROJECTS](../README.md)

## Overview

Sobremesa is an independent café management and life simulation game set in a stylized interpretation of Manizales, Colombia.

## My contribution

I work on gameplay programming, interactive system design, and the browser-based 3D experience.

## Project scope

- Interactive 3D environments
- Player interactions and gameplay logic
- Production systems
- Resource management

## Technologies

JavaScript · Three.js · HTML · CSS · Git

## Status

In development since September 2026. This is an evolving independent project, not a completed commercial release.
