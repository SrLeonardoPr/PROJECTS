## Overview

NanoExplora Colombia is an independent web development and science communication project designed to make nanotechnology more accessible to students and science enthusiasts.

## My contribution

I combine Engineering Physics, interface design, and interactive web experiences to explain scientific concepts.

## Project scope

- Visual exploration of microscopic and nanoscale dimensions
- Introduction to materials characterization techniques
- Educational content about nanotechnology applications
